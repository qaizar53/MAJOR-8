Developed a full-stack **Patient Management and Therapy Scheduling System (AyushSutra)** to digitize and streamline patient records, treatment history, and clinic operations for Ayurvedic and wellness centers. Implemented an intelligent appointment and therapy scheduling module that manages therapist availability, prevents booking conflicts, and optimizes resource utilization. Built role-based dashboards for patients, practitioners, and administrators to manage appointments, track treatment progress, and generate operational reports, thereby improving overall workflow efficiency and user engagement.
